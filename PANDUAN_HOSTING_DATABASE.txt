========================================================================
PANDUAN LENGKAP HOSTING PROYEK (MODE DOCKER) & KONEKSI DATABASE MSS SERVER
========================================================================
Diperbarui pada: v1.1.9 (Disempurnakan sesuai praktik langsung di server)

Panduan ini mencakup langkah demi langkah meng-hosting proyek Laravel dari GitHub
(https://github.com/Afiqq19/portofoliome.git) ke server Linux Toshiba menggunakan DOCKER,
terhubung ke Database Panel (mss-db), dan di-onlinekan via Cloudflare Tunnel.

------------------------------------------------------------------------
LANGKAH 1: SIAPKAN DATABASE KOSONG DI PANEL
------------------------------------------------------------------------
1. Buka MSS Server Panel di browser:
   https://panel.xie.my.id
2. Masuk ke menu "Database Manager" di sebelah kiri.
3. Di tab "Visual Explorer", klik tombol bulat warna biru dengan tanda Plus (+).
4. Masukkan nama database untuk proyek portofolio:
   Nama DB: db_portofolio
5. Pada pilihan Mesin Database, pilih wadah yang diinginkan:
   Mesin: mss-db
6. Selesai! Database kosong sudah siap digunakan.

------------------------------------------------------------------------
LANGKAH 2: MASUK KE SERVER & CLONE PROYEK
------------------------------------------------------------------------
1. Masuk via SSH atau Terminal Web MSS Panel ke server Linux Toshiba:
   ssh mss@192.168.1.100
2. Masuk ke direktori web server:
   cd /var/www/
3. Unduh repositori dari GitHub:
   git clone https://github.com/Afiqq19/portofoliome.git
4. Masuk ke folder proyek:
   cd portofoliome

------------------------------------------------------------------------
LANGKAH 3: KONFIGURASI DOCKER (DOCKERFILE & DOCKER-COMPOSE)
------------------------------------------------------------------------
Di dalam folder proyek (/var/www/portofoliome), pastikan kedua file ini ada:

1. File `Dockerfile`:
   (Gunakan PHP versi 8.3 Apache sesuai standar Laravel terbaru)

   FROM php:8.3-apache
   RUN apt-get update && apt-get install -y libzip-dev zip git libpq-dev default-mysql-client && docker-php-ext-install pdo_mysql pdo_pgsql zip
   RUN a2enmod rewrite
   ENV APACHE_DOCUMENT_ROOT /var/www/html/public
   RUN sed -ri -e 's!/var/www/html!${APACHE_DOCUMENT_ROOT}!g' /etc/apache2/sites-available/*.conf
   RUN sed -ri -e 's!/var/www/!${APACHE_DOCUMENT_ROOT}!g' /etc/apache2/apache2.conf /etc/apache2/conf-available/*.conf
   RUN sed -i 's/AllowOverride None/AllowOverride All/g' /etc/apache2/apache2.conf
   COPY --from=composer:latest /usr/bin/composer /usr/bin/composer
   COPY . /var/www/html
   RUN chown -R www-data:www-data /var/www/html

2. File `docker-compose.yml`:
   (Mengarahkan Port 9001 host ke Port 80 Apache container)

   version: '3.8'
   services:
     web_portofolio:
       build: .
       container_name: syafiq_portofolio
       restart: always
       ports:
         - "9001:80"
       volumes:
         - .:/var/www/html

------------------------------------------------------------------------
LANGKAH 4: HUBUNGKAN KONEKSI DATABASE (.ENV)
------------------------------------------------------------------------
1. Buat file .env dari template:
   cp .env.example .env
2. Edit file .env:
   nano .env
3. Sesuaikan konfigurasi database agar terhubung langsung ke wadah mss-db:


   DB_CONNECTION=mysql
   DB_HOST=mss-db
   DB_PORT=3306
   DB_EXTERNAL_PORT=3307
   DB_DATABASE=db_portofolio
   DB_USERNAME=root
   DB_PASSWORD=root_secret_pass

   (Catatan: Jika menggunakan PostgreSQL, ganti DB_CONNECTION=pgsql, DB_PORT=5432, dan DB_USERNAME=postgres)
4. Simpan perubahan: Tekan CTRL+O, Enter, lalu CTRL+X.

------------------------------------------------------------------------
LANGKAH 5: JALANKAN DOCKER, KUNCI AKSES, & MIGRATE
------------------------------------------------------------------------
1. Bangun dan hidupkan container Docker:
   docker compose up -d --build

2. Gabungkan jaringan container ke jaringan panel MSS (agar mss-db terbaca):
   docker network connect mss-server-panel_mss-network syafiq_portofolio

3. Berikan hak akses file .env dan storage agar tidak terjadi permission denied:
   docker exec -u root -it syafiq_portofolio chown www-data:www-data /var/www/html/.env
   docker exec -u root -it syafiq_portofolio chmod 777 /var/www/html/.env
   docker exec -u root -it syafiq_portofolio chmod -R 777 /var/www/html/storage /var/www/html/bootstrap/cache

4. Jalankan dependensi, pembuatan App Key, dan migrasi database:
   docker exec -it syafiq_portofolio composer install
   docker exec -it syafiq_portofolio php artisan key:generate
   docker exec -it syafiq_portofolio php artisan config:clear
   docker exec -it syafiq_portofolio php artisan migrate
   docker exec -it syafiq_portofolio php artisan storage:link

------------------------------------------------------------------------
LANGKAH 6: AKSES WEBSITE (LOKAL & DOMAIN ONLINE)
------------------------------------------------------------------------
1. Akses Lokal Server:
   Buka browser di jaringan lokal:
   http://192.168.1.100:9001

2. Online ke Domain Publik (via Cloudflare Zero Trust Tunnel):
   - Buka Cloudflare Zero Trust Dashboard (Networks > Tunnels).
   - Masuk ke tunnel server Toshiba Anda.
   - Tambahkan Public Hostname baru:
       Domain: mhdsyafiqsyahmi.my.id
       Service Type: HTTP
       URL: 192.168.1.100:9001
   - Klik Save Hostname.

------------------------------------------------------------------------
LANGKAH 7: FITUR SAKTI DI ROUTES/WEB.PHP (AUTO-DEPLOY & AKUN ADMIN)
------------------------------------------------------------------------
Agar Bapak bisa mengupdate website otomatis tanpa SSH setiap kali ada kodingan baru di GitHub, dan bisa membuat akun admin instan di database baru, selalu tambahkan kode sakti ini di paling bawah file `routes/web.php`:

// A. AUTO-DEPLOY WEBHOOK (Update website otomatis lewat browser)
Route::get('/update-rahasia-(terserah-apa-saja)', function () {
    set_time_limit(0); 

    $repoDir = base_path();

    // Auto-patch .env untuk URL domain & timezone
    $envFile = base_path('.env');
    if (file_exists($envFile)) {
        $env = file_get_contents($envFile);
        $env = preg_replace('/^APP_URL=.*/m', 'APP_URL=https://namadomainmu.my.id', $env);
        if (!str_contains($env, 'APP_TIMEZONE=')) {
            $env .= "\nAPP_TIMEZONE=Asia/Jakarta\n";
        } else {
            $env = preg_replace('/^APP_TIMEZONE=.*/m', 'APP_TIMEZONE=Asia/Jakarta', $env);
        }
        file_put_contents($envFile, $env);
    }

    $gitPath = 'git';
    putenv('GIT_TERMINAL_PROMPT=0');
    putenv('GCM_INTERACTIVE=false');

    $output0 = shell_exec("cd \"$repoDir\" && \"$gitPath\" config --global --add safe.directory \"*\" 2>&1");
    $output1 = shell_exec("cd \"$repoDir\" && \"$gitPath\" fetch --all 2>&1");
    $output2 = shell_exec("cd \"$repoDir\" && \"$gitPath\" reset --hard origin/main 2>&1");
    $output3 = shell_exec("cd \"$repoDir\" && composer install --no-interaction --prefer-dist --optimize-autoloader 2>&1");
    $output4 = shell_exec("cd \"$repoDir\" && php artisan migrate --force 2>&1");
    $output_clear = shell_exec("cd \"$repoDir\" && php artisan optimize:clear 2>&1");
    $output_link = shell_exec("cd \"$repoDir\" && php artisan storage:link 2>&1");
    
    return "<div style='font-family: monospace; background: #0f172a; color: #38bdf8; padding: 2rem; border-radius: 1rem; max-width: 900px; margin: 2rem auto;'>
                <h1 style='color: #4ade80;'>🚀 Auto-Deploy Berhasil!</h1>
                <pre style='background: #020617; color: #a3e635; padding: 1.5rem; border-radius: 0.75rem; overflow-x: auto;'>
[GIT FETCH & PULL]
" . htmlspecialchars((string) $output1) . "
" . htmlspecialchars((string) $output2) . "

[COMPOSER INSTALL]
" . htmlspecialchars((string) $output3) . "

[DATABASE MIGRATE]
" . htmlspecialchars((string) $output4) . "
                </pre>
                <a href='/' style='background: #6366f1; color: white; padding: 0.6rem 1.2rem; border-radius: 0.5rem; text-decoration: none; font-weight: bold;'>Buka Website</a>
            </div>";
});
